# JS Agent

A Smart JavaScript Automation Agent web application rewritten in React, TypeScript, and Tailwind CSS with Google Gemini AI integration.

## Features
- **Dark Matrix AI Design**: Faithful reproduction of the original Dark Matrix visual identity (`#080B09` dark canvas, `#00E676` matrix green accent, monospace typography, glowing borders).
- **Floating Assistant Overlay**: Draggable floating bubble with pulsating status indicators and expandable quick-control panel.
- **Automated JavaScript Repair Loop**: AI-powered code generation with Gemini 2.5 Flash, self-healing syntax & purity validator, bracket balance enforcement, and local heuristic fallback.
- **Page Structural Inspector**: Real-time visualization of window nodes, candidate question detector, input target mapping, and action button candidates.
- **Interactive Sandbox / Demo Playground**: 4 real JavaScript programming challenges with in-browser execution sandbox, automated test runner, and instant pass/fail validation feedback.
- **Settings & Preferences**: Toggle floating assistant, accessibility analysis engine, and developer inspector mode.

## Tech Stack
- **Framework**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **AI Integration**: `@google/genai` (Gemini 2.5 Flash via proxy server)
